# Calculate pairwise Euclidean distances

Calculate pairwise Euclidean distances

## Usage

``` r
calculate_pairwise_distances(train_coords, test_coords)
```

## Arguments

- train_coords:

  Matrix of training coordinates (n_train x 2)

- test_coords:

  Matrix of test coordinates (n_test x 2)

## Value

Vector of all pairwise distances
